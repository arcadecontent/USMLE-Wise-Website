AUTO-GENERATED RESULTS LANGUAGE

Quick teaching reference: every term explained
Run chart

A measure plotted in time order. It helps reveal variation, possible shifts, and whether improvement lasts.

Baseline

The observations collected before a change is tested. This is the comparator, not the ultimate goal.

Median

The middle observation after sorting values. This lab fixes the pre-change median as a reference line.

PDSA cycle

Plan, Do, Study, Act: a structured small test of a proposed change, followed by learning and adaptation.

Shift

A string of observations on the same side of the median. We use an 8-point convention for this 24-point demonstration.

Common-cause variation

Normal variation within a process. A pattern may suggest another influence, but the graph alone cannot identify it.

Percentage point (pp)

The absolute difference between percentages. Moving from 40% to 70% equals +30 pp, or a 75% relative increase.

Run chart versus control chart

A run chart compares values over time with a median. A control chart also uses statistically calculated limits to analyze process variation.

Method and limitations. This is a simulated 24-week dataset, not a result from any of the papers above. For a 24-point chart, this lesson uses the 8-point shift convention from the IHI run-chart reference sheet. Other teaching resources use 6 points and guidance varies with dataset length. Points exactly on the median are skipped when counting a run. This lesson checks the shift rule only; it does not test trends, total numbers of runs, or unusual points. Signal detection is not proof of causation. In real projects, document denominators, measurement definitions, changes in patient mix and other concurrent events. IHI run chart rules · AAP clinical QI interpretation guide.
